# OctaBoss — гайд

Фреймворк животных-боссов от **Octavian**. Один плагин вместо зоопарка
клонов: в конфиге — список видов, у каждого свои статы, свита, лут,
расписание, биом и анонсы. Из коробки настроены **бык** и **кабан**,
ещё 5 видов лежат заготовками и включаются одним полем.

Файлы на сервере:

- Плагин: `carbon/plugins/OctaBoss.cs`
- Конфиг: `carbon/configs/OctaBoss.json`

| `/bossinfo` | живые боссы: HP, квадрат, топ-дамагер |

### Админ (консоль/RCON, требуют `IsAdmin`)

| Команда | Что делает |
|---|---|
| `octaboss.list` | статус всех видов в консоль |

### Панель `/boss_admin` (v1.6.0)

Командная панель: тёмное стекло + золото, окно 0.66 экрана.

- **Слева** — вертикальные карточки видов (имя, статус ЖИВ/OFF/минуты,
  цветная полоса состояния) и 8 вкладок:
  ОБЗОР / БОЕЦ / ФАЗЫ / СВИТА / СПАВН / НАГРАДЫ / СООБЩЕНИЯ / ОПАСНАЯ.
- **Шапка** — картинка зверя через ImageLibrary (поле
  `Картинка для админ-панели` в конфиге; пусто → буква-фолбэк),
  имя, индикатор «● ЕСТЬ НЕСОХРАНЁННЫЕ ИЗМЕНЕНИЯ».
- **Статус-карта** — HP-полоса (цвет по фазе), бейдж фазы,
  квадрат и время на карте.
- **Черновик**: все правки идут в Draft, в конфиг пишутся только
  по СОХРАНИТЬ (+валидация: P3 < P2, клампы диапазонов).
  ОБНОВИТЬ отбрасывает черновик (с подтверждением при изменениях).
- **Степперы** `−`/`+` + шкала + ручной ввод (CUI-слайдеры ненадёжны),
  тоглы ВКЛ/OFF, подсветка ⚠ на опасных значениях.
- **Пресеты** на ОБЗОР: PVP-ЛЁГКИЙ/СТАНДАРТ/ХАРДКОР/PVE-ТЕСТ
  (применяются к черновику после подтверждения).
- **СООБЩЕНИЯ** — список событий, одно большое поле, навигатор
  вариантов предупреждения ←/→ + добавить/удалить.
- **ОПАСНАЯ** — тихий деспавн, спавн через 1 мин, сброс трекера,
  перечитать конфиг с диска. УБИТЬ/ДЕСПАВН — через подтверждение.
- **СПАВН** — кнопка «⊕ МОНУМЕНТ РЯДОМ СО МНОЙ» добавляет/убирает
  ближайший монумент в якоря без ручной правки строки.
- Тосты 2.5 сек внутри панели вместо спама в чат.

Права: `octaboss.admin` = всё; гранулярно —
`octaboss.admin.view` (открыть), `.edit`, `.spawn`, `.kill`,
`.rewards`, `.messages`, `.presets`. Без права поля видны,
но неактивны (🔒).

(`c.grant user <steamid> octaboss.admin` — см. PITFALLS §15 про `c.grant`.)

## Ключевая механика

### Награды: команда и топ-дамагер, не ласт-хит

Урон считается **по команде**: ключ участника — ID нативной тимы Rust
(`player.Team`), соло-игрок — сам себе команда. Победившая команда —
та, что нанесла больше всего урона суммарно; внутри неё основная
награда делится **пропорционально личному урону**. Доля < 10% —
без выплаты основной награды (защита от балласта в скваде).

Добивший получает только строчку в анонсе — голый с камнем килл
не украдёт. Мелкое участие платится максимум **топ-5** дамагерам
выше порога `Порог участия` (дефолт 5% общего урона).

Получатель баффа **раскрывается в анонсе по квадрату карты** —
цена за усиление: все знают, где искать героя метки.

### Фазы босса: P1 → P2 → P3

По доле HP босс меняет поведение (пороги и множители — на вид):

| Фаза | HP | Что меняется |
|---|---|---|
| P1 «Пасущийся» | > `Фаза 2: порог входа` (0.8) | базовый урон/агро/скорость |
| P2 «Разъярённый» | ≤ 0.8 | урон ×1.15, агро 120м, скорость ×1.15, ретаргет по угрозе |
| P3 «Последний рывок» | ≤ `Фаза 3: порог входа` (0.3) | урон ×1.35, агро 150м, скорость ×1.35, рывок+AoE, паника свиты |

На переходы P2/P3 есть анонсы. P3-рывок: каждые `Фаза 3: рывок ... (сек)`
(дефолт 15, 0=выкл) босс дэшится к самому дальнему дамагеру и бьёт
по площади: ×1.0 в ≤3м, ×0.5 в ≤7м, дальше — 0. Разойтись = пережить.
После рывка 3 сек щит −25% входящего урона — добивать в окне
невыгодно, ждите перезарядку.

### Таблица угрозы

Параллельно DamageBy копится threat: каждые 5 сек затухает ×0.92 —
старый урон забывается, свежая активность важнее. Цель выбирается
по очкам `threat × модификатор дистанции` (1.0 в 30м / 0.7 в 60м /
0.4 в 120м) и меняется только если новый кандидат превосходит
текущего в **1.35 раза** — босс не мечется между двумя стрелками.

### Свита: роли и паника

При спавне свита делится на роли: первые `ceil(N × 0.6)` — **охрана**
(держится у босса, leash 50м, агрится на его цель), остальные —
**приманки** (бегут на ближайшего игрока, жгут ему патроны).
На P3 часть свиты разбегается (`Фаза 3: часть свиты разбегается`,
дефолт 0.4 — тихий деспавн), остальные входят в ярость на 60 сек.
После смерти босса свита живёт 60 сек паники и деспавнится —
бесплатного мяса у места килла нет.

### Спорный лут: мешок закрыт 10 секунд

Мешок появляется `Naked` и `Награды.Мешок закрыт после смерти (сек)`
(дефолт 10) никого не пускает — всем виден таймер открытия.
Победившая команда должна пережить финальную фазу: чужие могут
ворваться и перехватить контейнер. Валюта/бафф идут команде
автоматом, а содержимое мешка — это уже PvP.

### Зализывание ран (анти-добивание)

Если по боссу `Перезарядка боя` секунд (дефолт 60) никто не наносил
урон от игроков:

- HP регенится `Реген % макс. HP в секунду` (дефолт **2.5%** —
  полный реген ≈40 сек, а не 10);
- при ≥95% HP бой считается **полностью сброшенным**: ярость снята,
  трекер урона и угроза очищены, анонс `Текст зализывания ран`
  один раз на сброс.

Итог: команда отступила на минуту → весь прогресс тает, но не
мгновенно — вернуться и додавить ещё можно.
`Перезарядка боя = 0` выключает механику на виде.

### Смерть без боя = без лута

Лут и награды выпадают только при реальном бое (урон от игроков или
добивший-игрок). `DieOffNavmesh`, утопление, смерть от зверей —
туша без мешка и без RP, с анонсом `Текст смерти без боя`.
Крокодила больше нельзя выманить с навмеша за бесплатный лут.

### Босс не убегает из боя (Gen2 FSM)

Бегство в Gen2 — реальные состояния графа (`State_Flee` и наследники:
`FleeToHide` у кошек, `FleeFire`, `HerdFlee` у скотины), а не ключи
blackboard — поэтому старый приём «сносить факт `flee`» переход не отменял.

При спавне босса `TameFlee` правит граф **на его экземпляре** (обычные
животные не затрагиваются): каждый переход, ведущий в flee-состояние,
перенаправляется:

- **боевые** («ударил-убежал» тигра, паника от урона/взгляда/выстрела,
  hurt→flee, attack→flee) → обратно в боевое состояние
  (`approach`/`chase`/`chargeRun`/`warnApproach` по виду);
- **легитимные отступления** (сейф-зона, вода, огонь, недосягаемая цель,
  сдача энкаунтера) → `roam`: босс спокойно отходит, а не бежит
  поджав хвост, и внешне это честный разрыв боя.

Крокодил пропускается целиком: его `GoBackToWater` — штатный засадный
цикл (нырнул → выпрыгнул), а не паника. Дополнительно у базового зверя
обнуляется `fleeBelowHealthFraction`, а сторож в боевом тике выводит
босса из flee штатным `fsm.SetState(...)`, если переход всё же
проскочил (напр. до «приручения» или по непредусмотренному пути).

### Биомы и вода

```json
"Спавн только в родном биоме": true,
"Родные биомы ...": "jungle",
"Требовать воду рядом": true,
"Радиус поиска воды ... (м)": 30.0
```

- Биом — `TerrainBiomeMap.GetBiomeMaxType` точки ∈ списка
  (`arid, temperate, tundra, arctic, jungle`).
- Вода — точка на суше (`h ≥ 1.5`), но по кругу 8 проб хотя бы одна
  должна быть под водой. Для водных видов топология пляжа/берега
  не отсекается.
- Цепочка фолбэков: **биом+вода → вода без биома → любая точка**
  (с warning'ами в лог — ивент никогда не теряется).

### Спавн у монумента — «кольцо Сатурна»

Если заданы `Монументы-якоря` (частичное совпадение, напр.
`ranch,barn,stables` — на новых картах ранчо = конюшни `stables_*`),
босс спавнится в кольце `мин..макс м` от края
случайного подходящего монумента. Точки **внутри любого другого
монумента** отсекаются — сейф-зоны (аутпост/бандитка) исключены.
У кабана дефолт 300–900м: не кемпится на точке, но всегда у жилья.

### Туши и масштаб

Масштаб и пол ставятся **до `Spawn()`** — иначе снапшот уходит клиенту
с дефолтом. Труп — отдельная entity: матчится в `OnEntitySpawned` по
`parentEnt`, фолбэк — свежая запись по позиции смерти (TTL 5 мин,
радиус 8м). Трупы игроков/учёных/лошадей отфильтрованы.
Свита тоже регистрируется — поросята x0.55 не «вырастают».

### Расписание

`Интервал спавна ± Разброс` минут между появлениями. Первый спавн
после рестарта/загрузки — случайные 5–45 мин, чтобы весь зверинец
не спавнился одновременно предсказуемым вайп-фармом.

## Конфиг

### Верхний уровень

```json
{
  "Виды боссов": [ ... ],
  "Уведомления": {
    "Глобальный чат": true,
    "Имя плагина в чате (бренд перед текстом)": "◆ OctaBoss",
    "Discord webhook (пусто = выкл)": ""
  }
}
```

`Имя плагина в чате` — бренд всех сообщений. Для перепродажи:
`"Warbandit Boss"` → `Warbandit Boss Кто хочет поиграть в выжившего?...`

### Поля вида (BossSpec)

| Поле | Тип | Описание |
|---|---|---|
| `Включён` | bool | участвует в расписании |
| `Ключ` | string | для команд, латиница, **уникальный** (дубль = потеря вида + PrintError) |
| `Префаб босса` | string | путь префаба из бандла |
| `Имя босса` | string | в анонсах и как имя животного |
| `Пол босса` | bool? | `true`/`false`/пусто = как у префаба (LivestockAnimal) |
| `Здоровье` | float | HP на спавне |
| `Множитель входящего урона` | float | пули / взрывы / остальное (броня) |
| `Иммунитет к ...` | bool | огонь/кровотечение/яд/холод/радиация = 0 |
| `Множитель исходящего урона` | float | урон босса по игрокам |

| `Макс. время жизни (мин)` | float | деспавн по старости (анонс, без лута) |

| `Множитель скорости` | float | все пороги скорости RustNavMeshAgent |

| `Форс-агро Provoke` | bool | для скотины: Provoke/RememberAggressor на ближайшего |
| `Перезарядка боя` | float | сек без урона до регена; 0 = выкл |
| `Реген % макс. HP в секунду` | float | скорость зализывания ран (дефолт 2.5) |
| `Фаза 2: порог входа` / `Фаза 3: порог входа` | float | доля HP входа в P2 (0.8) / P3 (0.3) |
| `Фаза N: множитель исходящего урона` | float | 1.15 / 1.35 |
| `Фаза N: радиус агро (м)` | float | 120 / 150 |
| `Фаза N: множитель скорости` | float | 1.15 / 1.35; 1.0 = без разгона |

| `Фаза 3: урон рывка по площади` | float | база AoE до множителей |

смысл полей виден по их JSON-названиям.

### Анонсы

У каждого вида шаблоны с `{name}` = имя босса и `{0}` = аргумент
(квадрат / минуты / добивший):

- `Текст анонса спавна`, `Текст предупреждения`, `Текст деспавна`,
  `Текст смерти`, `Текст смерти без боя`, `Текст ярости`,
  `Текст зализывания ран`
- `Варианты предупреждения` — список фраз, случайный выбор
  (пусто → `Текст предупреждения`). Из коробки по 5 флейворных
  фраз на вид — Шерхан, Ричард Паркер, Гена, ДиКаприо и пр.

Ники игроков в анонсах санитизируются от `<>` — инъекция
rich-text-тегов через ник невозможна.

### Лут (LootEntry)

```json
{ "Шортнейм предмета": "scrap", "Мин. кол-во": 1500, "Макс. кол-во": 3000,
  "Шанс (0-1)": 1.0, "Скин ID (0 = без)": 0,
  "Чертёж: целевой предмет (если задан)": "",
  "Пул (0 = сам по себе, >0 = один предмет из пула)": 0 }
```

**Пул** — главная защита от «склада оружия» в одном мешке:
`0` = независимый шанс как раньше; `N > 0` = из всех записей
с этим N выпадает **ровно один** предмет, `Шанс` работает весом.
Из коробки: пул 1 = оружие (M249/LR-300/L96/ракетница/SPAS — один из),
пул 2 = utility (карты/взрывные боеприпасы), 0 = гарант-ресурсы
и BP-шансы. Ожидаемая ценность мешка — ~2.5× стоимость боя,
а не джекпот за час до вайпа.

Чертёж: `Шортнейм = "blueprintbase"` + `Чертёж = "rifle.ak"`.
Мешок — `item_drop_backpack`, 30 слотов, имя = имя босса,
лутать может кто угодно (`onlyOwnerLoot = false`), время жизни
`Время жизни мешка с лутом` (дефолт час), первые `Мешок закрыт
после смерти (сек)` (дефолт 10) мешок закрыт — см. «Спорный лут».
Предметы сверх 30 слотов отбрасываются молча — не раздувай таблицу.

## Траблшутинг

| Симптом | Причина |
|---|---|
| Крокодил спавнится и тут же дохнет | `Требовать воду рядом = false` или воды нет — `DieOffNavmesh` у Gen2 |
| Тигр/пантера не спавнятся | На карте нет джунглей — смотри warning «биом не найден» в логе, ивент уйдёт в фолбэк |
| Туша обычного размера | Труп не попал в матч — см. PITFALLS: масштаб только в снапшоте, апдейты его не несут |
| Вид не спавнится вообще | `Включён = false`, или дубль `Ключ` в конфиге (PrintError в логе) |
| Награды не приходят | Нет ServerRewards/Economics, либо босс умер без боя |
| Босс убит админом — лут есть | Норма: админ-килл = конец ивента с лутом, без RP-наград |

## Безопасность (что закрыто)

- Награда топ-дамагеру + кап 5 участников — kill-steal и альт-фарм мимо
- Лут только за реальный бой — смерть от окружения бесплодна
- Ответка на урон с любой дистанции — снайпер с 200м зовёт босса на себя
- Ник-инъекция rich text вырезана
