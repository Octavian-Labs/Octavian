# OctaBoss → PvP-ивент: план работ

Цель: из «большой кабан с лутом» сделать полноценное серверное PvP-событие —
фазы босса, таблица угрозы, роли свиты, командные награды и спорный лут.

## Этап 1 — критичные фиксы и баланс

- [x] `DeathHandled`-флаг в `HandleBossDeath` (защита от двойного лута/наград/анонсов
      при гонке Kill() ↔ OnEntityDeath; сброс флага при новом спавне)
- [x] Кап трекера урона: `min(effectiveDamage, currentHealth)` —
      оверкилл не должен завышать DamageBy
- [x] Реген: дефолт 10%/сек → 2.5%/сек (полный реген 40 сек);
      при HP ≥ 95% — бой считается сброшенным: ярость снята, DamageBy очищен,
      анонс «зализал раны» один раз на сброс
- [x] Свита после смерти босса: 60 сек паники → деспавн
      (не остаётся на карте, не бесплатное мясо у места килла)
- [x] Спорный лут: мешок закрыт первые 10 сек после смерти
      (поле `Награды.Мешок закрыт после смерти (сек)`, CanLootEntity,
      игрокам виден таймер открытия)

## Этап 2 — командные награды и фазы

- [x] Награды по команде: ключ участника = ID нативной тимы Rust
      (`player.Team`), иначе SteamID. Победившая команда — макс. суммарный
      урон; внутри команды валюта делится пропорционально урону;
      доля < 10% → без выплаты основной награды
      (Clans-плагин на сервере нет — если появится, добавить к нему фолбэк)
- [x] Фазы босса по HP: P1 «Пасущийся» (>80%), P2 «Разъярённый» (30–80%),
      P3 «Последний рывок» (≤30%). На фазу: множитель исходящего урона
      (`PhaseDmgMult`), радиус агро (`AggroOf`), анонсы перехода.
      Скорость в рантайме: `RustNavMeshAgent.speed` меняется живьём —
      реализовано через `ApplyPhaseSpeed` (делится накопленный множитель,
      чтобы не перемножалось каждый тик)
- [x] P2: пересмотр цели по threat-таблице (не ближайший, а по очкам угрозы);
      охранники свиты получают целью текущего танка/последнего стрелка
- [x] Таблица угрозы `ThreatBy` + `RecentHits`:
      threat прибавляется при уроне (фактический, после брони и капа HP);
      decay ×0.92 каждые 5 сек; смена цели только при
      NewScore > Current × 1.35 (гистерезис), модификатор дистанции
      1.0 / 0.7 / 0.4 (30/60/120м)
- [x] Бафф победителя раскрывает его квадрат в анонсе
      («герой метки» — цена за бафф, квадрат считается `GridOf`)

## Этап 3 — лут-пулы и роли свиты

- [x] `LootEntry.Пул`: 0 = независимый шанс (старое поведение),
      N>0 = из каждого пула выпадает ровно 1 предмет (вес = Chance);
      живой конфиг переразбит: пул 1 = оружие, пул 2 = utility,
      0 = гарант + BP-шансы (70 записей у 7 видов)
- [x] Роли свиты: `Guard = ceil(N × 0.6)` — leash 50м (возврат телепортом)
      и агро на цель босса/последнего стрелка; `Decoy = остальные` —
      провоцируются на ближайшего игрока в 60м (жгут патроны)
- [x] Паника свиты на P3 (≤30% HP босса): часть разбегается — тихий
      деспавн (`Фаза 3: часть свиты разбегается`, дефолт 0.4),
      остальные `MarkHostileFor(60)` — ярость
- [x] P3-рывок каждые 15 сек (настраивается, 0=выкл): дэш к самому
      дальнему дамагеру + AoE-урон (1.0 ≤3м / 0.5 ≤7м / 0 дальше) +
      щит −25% входящего на 3 сек (`LeapShieldUntil`)
- [ ] Тест полного цикла на сервере: спавн → фазы → смерть → лут → награды
      (смоук спавн/килл пройден, живой бой — за игроками на тесте)
- [ ] Обновить `Guides/OctaBoss.md` новыми механиками и полями конфига

## Известные ограничения (приняты)

- «Лечение союзников» в threat не учитывается — нет дешёвого способа
  отследить, кто кого лечил (пропускаем)
- Скорость в рантайме у Gen2-зверей меняется через `RustNavMeshAgent.speed`;
  визуальная плавность на анимациях не проверялась — при дёрганье
  выставить множители скорости фаз в 1.0
- AoE-рывок телепортом может ломать навмеш крокодила — выключается
  по видам через `Фаза 3: рывок ... (сек, 0=выкл)`
- Провокация свиты (`Provoke`/`MarkHostileFor`) у скотины Gen2 работает
  нестабильно — охрана безусловно держит leash 50м, агро — как получится
