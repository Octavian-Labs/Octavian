# Octavian Admin-UI — стиль и паттерны

Эталон: админ-панель `OctaBoss` (v1.6+). Использовать для любых новых
игровых панелей (CUI) в плагинах Octavian. Стиль — «командная консоль:
золото на чёрном стекле».

## Палитра (константы)

```csharp
GoldBright = "0.95 0.75 0.30 1"  // активный элемент, предупреждения
Gold       = "0.82 0.61 0.20 1"  // акценты, кнопки, подчёркивания
GoldDark   = "0.48 0.32 0.10 1"  // тонкие линии, тёмные кнопки
GoldGlass  = "0.82 0.61 0.20 0.18" // выделенная строка/вкладка
GlassBg    // тёмная «стеклянная» панель (полупрозрачный чёрный)
GlassRow   // фон строки настроек
GlassLt/GlassHov // пассивная/активная кнопка
TWhite = "1 0.98 0.90 1"         // основной текст (тёплый белый)
TMain  = "0.93 0.88 0.75 1"      // вторичный текст
TMued  = "0.58 0.53 0.43 1"      // серые подписи/пояснения
CGreen / CRed / CBlue            // тосты и опасные действия
CHpBg  = "0.10 0.05 0.04 0.95"   // фон HP-бара
```

## Каркас панели

- Один корневой панель `AdminUIName`, под-элементы с именами `UiN("XXX")`
  — перерисовка ТОЛЬКО нужных частей (HDR/CNT/TAB/BOT/TST/CFM), без
  полного rebuild: `UiRefresh(player, "CNT", "HDR")`.
- Шапка: иконка `M` слева, `◆ НАЗВАНИЕ — КОНТЕКСТ` заголовок, строка
  состояния («ЕСТЬ НЕСОХРАНЁННЫЕ ИЗМЕНЕНИЯ», «НЕТ НА КАРТЕ • спавн через ~N мин»),
  красная ✕ справа.
- Левая колонка: список сущностей (виды боссов) — вертикальный список,
  выбранный пункт золотой строкой, под именем статус мелким шрифтом.
- Под списком — вертикальные вкладки (ОБЗОР/БОЙ/ФАЗЫ/СВИТА/СПАВН/НАГРАДЫ/
  СООБЩЕНИЯ/ОПАСНАЯ). Активная — GoldGlass фон + GoldBright текст.
- Контент — две колонки ~0.49 ширины; нижняя панель — быстрые действия.

## Элементы

- `DrawSection` — золотой заголовок секции 10pt + тонкая линия GoldDark.
- `DrawStepper` — числовое поле: подпись | [−] [ввод] [+]; поле — реальный
  `CuiInputFieldComponent` + `CuiNeedsCursorComponent` (ручной ввод!);
  `WarnIf` → оранжевая подсветка строки + ⚠-подсказка.
- `DrawToggle` — ВКЛ/ВЫКЛ кнопка (CGreen/GlassLt).
- `DrawTextRow` — строковое поле с вводом.
- `info(...)` — серая пояснительная строка 10pt (итоговые множители и пр.).
- `DrawPresetBar` — полоса пресетов сверху контента.
- `DrawMonumentPick` и подобные кастом-блоки — рисуются вручную, но
  ОБЯЗАТЕЛЬНО сдвигают каретку колонки (`yL -= высота`), иначе следующий
  элемент ляжет поверх.

## Правила укладки (иначе элементы наползают)

- Питчи: num-строка `0.098`, toggle `0.068`, text `0.092`, sec `0.055`,
  info `0.056`. Высота колонки контента ≈ `0.985 → 0` — сумму питчей
  держать ≤ 0.98; если больше — перебалансировать колонки.
- Проверять на 1366×768: шрифт 10-11pt, метки до ~20 символов.
- CUI НЕ клипает детей по границам панели — элемент за краем просто
  рисуется поверх соседнего UI.

## Модель данных

- `AdminUiState` на игрока: `BossKey`, `Tab`, `Draft` (клон BossSpec),
  `Dirty`, `Pending` (ожидаемое подтверждение), `Toast/ToastSeq`,
  `MsgId`, `WarnIdx`. Словарь `_ui[steamid]`.
- Черновик: ВСЕ правки идут в `st.Draft`, в конфиг — только по
  «СОХРАНИТЬ». Перед сохранением `ValidateDraft` клампит значения и
  возвращает warn-строку.
- Подтверждения: `st.Pending = "действие[:парам]"` → `UiDrawConfirm`
  (затемнение + модалка ОТМЕНА/ПОДТВЕРДИТЬ) → `case "confirm"`.
- Тосты: `UiToast(player, "✓ текст", CGreen)` — полоса над нижней
  панелью, самоочистка через 2.5с по `ToastSeq` (гонок нет).
- Права: `octaboss.admin` базовое + гранулярные `.view/.edit/.spawn/
  .kill/.rewards/.messages/.presets` — `Perm(player, "edit")` на каждое
  действие; без права кнопки серые и пустые (`Command = ""`).

## Поведение при сохранении

- Сохранённые настройки применяются к СЛЕДУЮЩЕМУ циклу/спавну — живой
  объект работает на слепке (`Live` vs `Spec` паттерн). Точечное
  применение к живому объекту — отдельная кнопка с подтверждением
  («ПРИМЕНИТЬ ЧЕРНОВИК К ЖИВОМУ»).
- Тост после сохранения прямо говорит: «Сохранено — живой босс на
  старых настройках».

## Прочее

- `arg.Args` — StringView, сравнивать через `.ToString()`.
- Картинки — мягкая зависимость `[PluginReference] ImageLibrary`
  (портреты боссов); без плагина — просто не рисуем.
- При Unload уничтожать ВСЕ части для всех игроков: `UiParts` +
  `AdminUIName` через `CuiHelper.DestroyUi`.
